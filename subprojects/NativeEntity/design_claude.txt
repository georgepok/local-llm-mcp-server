1. COMPUTATIONAL DECOMPOSITION — The task factors into four sub-computations. First, event-type routing: read the one-hot type channel and decide the operation (FILLER→hold, FALSE→hold/ignore, VALID_REL→overwrite the stored commitment, INVALID_REL→reject/hold, PROBE→read out). Because legitimacy is handed to the network as an explicit event type, no legitimacy judgment must be learned — only correct routing. Second, one-shot content capture: when VALID_REL fires, seize the accompanying symbol embedding and bind it as the current commitment. Third, persistent maintenance: hold that bound content unchanged across an arbitrary run of intervening events. Fourth, cue-free readout and decode: at a PROBE (where the symbol field is zeros) reproduce the stored embedding from an internal cue and turn it into symbol-vocabulary logits, while the action head emits the RESPOND action. The only genuinely adaptive piece is capture — everything else is fixed gating and fixed decoding.

2. MEMORY TIMESCALE — Two clocks. A fast, single-timestep clock carries the event-type gates and the momentary input embedding; these must vanish immediately so distractors leave no residue. A slow, effectively episode-length clock holds the current commitment: it must persist losslessly from the last VALID_REL until either the next VALID_REL or episode end, surviving unboundedly many FILLER/FALSE/INVALID/PROBE events in between. Retention is "infinite within the episode but instantly overwritable on command." Crucially there is no cross-episode memory: the plastic store is cleared to zero at episode onset (the fixed weights re-seed each run), so the slow memory is a within-episode register, not a lifetime one.

3. PLASTICITY TYPE — A three-factor, write-gated Hebbian (delta) rule on a fast associative weight matrix M that binds a fixed internal key vector k to the current symbol embedding e. The three factors are: pre-activity = the symbol-embedding input line (e), post-activity = the fixed key/slot neurons (k), and a third gating factor = the VALID_REL event unit acting as a neuromodulatory switch. The update is an overwrite, ΔM = g·(k·eᵀ − M): when the gate g≈1 (VALID_REL) it clears the old trace and writes the new binding in a single shot; when g≈0 (every other event) M is untouched. This rule is mandatory precisely because there are no gradients and the content to be stored is unknown at design time and novel within the episode — the specific symbol may never have been encountered. Backprop cannot help: it needs many examples and cannot bind a brand-new pattern in one step, and it is unavailable regardless. A local Hebbian outer-product write captures arbitrary presented content instantly. Reward is not required for the core write (the event gate suffices); optionally a correct-probe reward can be used only as a slow modulator of write gain or trace decay for extra robustness.

4. NEURAL MOTIF — A gated fast-weight register network. The input splits into (a) five event-type gate units (a fixed linear read of the one-hot) providing multiplicative three-factor gates, and (b) the symbol-embedding channel passed through an identity/orthogonal (lossless) projection. The recurrent state is not unit activity but the plastic matrix M — a one-slot key–value fast-weight memory (Hopfield/fast-weights family) whose fixed key is k. Writes are gated by the VALID_REL unit; all other gates route to hold/reject/respond without touching M. At readout, M is probed with the constant internal key k (never the input, which is zero at a PROBE), yielding the stored embedding ê = M k. A fixed decode stage correlates ê against the known random embedding dictionary E to produce symbol logits (logits = E ê). A fixed action head maps the five event-type gates to the five action logits (VALID_REL→UPDATE, INVALID_REL→REJECT, FALSE/FILLER→HOLD, PROBE→RESPOND). Total state and unit count scale with embedding width d ≤ 128, comfortably inside the size budget; an optional gated activity integrator (h←(1−g)h+g·e) can run in parallel as a redundant short-term backup.

5. PARAMETER REGIME — The dynamical regime is a deliberate line/plane attractor. Along the storage subspace the memory has eigenvalue exactly 1 (trace decay λ≈1), giving lossless, drift-free retention over arbitrarily long gaps; along all other directions eigenvalues are <1 so distractor and noise transients contract to zero within a step or two. The write gate uses a steep, high-gain sigmoid on the VALID_REL unit so writes are all-or-none — sharp binary routing that prevents FALSE/INVALID events (whose gates sit near zero) from leaking any partial write. The rule is delta/overwrite rather than additive, keeping M a palimpsest so no superposition crosstalk accumulates. The embedding dictionary is near-orthonormal random (Gaussian, d large enough that Johnson–Lindenstrauss keeps symbols roughly orthogonal), so a stored vector decodes to its own symbol with a wide margin and collisions are exponentially rare in d. Decode temperature is set so the top correlate dominates.

6. FAILURE MODES — (a) Held-out symbols, the central risk: any per-symbol trained readout would fail on novel symbols, so the design stores the presented embedding vector itself (content, not an index) and decodes by geometric correlation against the fixed dictionary — a never-seen symbol is stored and read back identically to a familiar one, and the embedding channel is kept lossless (orthogonal, no learned compression) to preserve decodability. (b) False adoption on FALSE/INVALID: mitigated structurally by wiring the write gate only to the VALID_REL unit with a steep threshold, so illegitimate events cannot write. (c) Probe-time erasure: a PROBE carries a zero embedding, which under a delta rule would wipe M toward zero — prevented because the write gate is zero on PROBE and readout uses the internal constant key k rather than the (empty) input. (d) Superposition/interference from stacked commitments: eliminated by the overwrite rule and old-trace clearing. (e) Slow drift over very long streams: avoided by setting storage eigenvalue to exactly 1, with the fixed-key autoassociation acting as periodic attractor cleanup. (f) Decode collisions between near-parallel random embeddings: reduced by choosing d large enough for an orthogonality margin, trading a few hidden units for exponentially lower error. (g) Viability death spiral: because capture and decode are deterministic with a wide margin, a correct binding stays correct until legitimately overwritten; the optional reward-modulated consolidation of the current trace is available only as a secondary safeguard, not a crutch.
