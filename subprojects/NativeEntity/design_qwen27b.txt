1. COMPUTATIONAL DECOMPOSITION
The task requires a strict separation between event classification and symbol binding. The network must first decode the event type to determine the operational mode: ignore for fillers, reject for invalid relations, update for valid relations, and query for probes. Crucially, the system must maintain a distinct internal representation of the current commitment symbol that is independent of the transient input stream. This decomposition implies a gating mechanism where the event type controls whether the symbol buffer is read, written, or left untouched, ensuring that distractors and false assertions do not corrupt the stored state.

2. MEMORY TIMESCALE
The memory component must operate on an episode-long timescale, persisting the current commitment symbol from the initial setup until the episode ends or a valid update occurs. This requires a stable attractor state or a persistent activation pattern that resists decay over the variable length of the event stream. The memory must be volatile enough to be overwritten by a VALID_REL event but robust enough to remain unchanged by FILLER, FALSE, or INVALID_REL events, effectively acting as a latch that holds the most recent legitimate symbol.

3. PLASTICITY TYPE
Since global backpropagation is forbidden, the network relies on local Hebbian-like plasticity driven by a reward signal that indicates probe correctness. Specifically, when a PROBE event occurs, the network compares its output symbol against the ground truth; if correct, a positive reward signal strengthens the synaptic connections between the current input embedding and the memory state, reinforcing the association for that specific symbol. If incorrect, a negative signal weakens these connections or triggers a reset mechanism. This local rule allows the network to "learn" the mapping of unseen symbols to internal memory slots within the single episode by associating the specific input vector with the required output response.

4. NEURAL MOTIF
The architecture consists of a small recurrent core with a dedicated memory module and a gating layer. The recurrent core processes the event type and symbol embedding, feeding into a gating unit that determines the flow of information. The memory module, implemented as a set of persistent units, stores the current commitment. The gating unit, driven by the event type, either passes the new symbol embedding to the memory module (on VALID_REL), blocks input (on FILLER/FALSE/INVALID_REL), or routes the memory state to the output layer (on PROBE). This motif ensures that the memory state is only updated when explicitly authorized by the event type, preventing contamination from distractors.

5. PARAMETER REGIME
The network must operate in a stable, low-dimensional dynamical regime where the memory states are deep attractors. The spectral radius of the recurrent weight matrix should be kept below one to ensure stability, preventing chaotic divergence during long event streams. However, the plasticity mechanism must introduce controlled instability during VALID_REL events to allow the memory state to shift to a new attractor corresponding to the new symbol. This balance ensures that the network can settle into a stable representation of the current commitment while remaining responsive to legitimate updates.

6. FAILURE MODES
A primary failure mode is the inability to generalize to unseen symbols, which occurs if the network relies on fixed, pre-trained symbol embeddings. To mitigate this, the plasticity rule must be symbol-agnostic, learning the association between the raw input vector and the memory state on the fly. Another failure mode is memory leakage, where distractors gradually corrupt the stored symbol. This is prevented by the strict gating mechanism that isolates the memory module from irrelevant inputs. Finally, catastrophic forgetting of the current commitment during long filler sequences is avoided by the stable attractor dynamics of the memory module, which maintains activation without external reinforcement.
