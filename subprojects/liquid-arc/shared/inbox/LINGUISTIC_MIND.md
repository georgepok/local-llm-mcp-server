### New Module: ConversationEmbedding

Create `liquid_arc/conversation_embedding.py`:

```python
"""Conversation embedding — event-as-token for linguistic state control.

Follows the same additive embedding pattern as RoboticsEmbedding:
  h = ContentProjection(content_embedding) + MetadataProjection(metadata)
      + TypeEmbed(event_type) + PosEmbed(position)
      → LayerNorm → Dropout

Content embedding is generated by a LOCAL model on the Spark
(sentence-transformers). Conversation data never leaves the device.
"""

import torch
import torch.nn as nn


class ConversationEmbedding(nn.Module):
    def __init__(
        self,
        d_model: int = 768,
        content_embed_dim: int = 384,
        n_metadata_features: int = 8,
        n_event_types: int = 8,
        max_events: int = 128,
        dropout: float = 0.1,
    ):
        super().__init__()
        self.d_model = d_model

        # Content projection: text embedding → d_model (MLP, not lookup)
        self.content_proj = nn.Sequential(
            nn.Linear(content_embed_dim, d_model),
            nn.GELU(),
            nn.Linear(d_model, d_model),
        )

        # Metadata projection: scalar features → d_model
        self.metadata_proj = nn.Sequential(
            nn.Linear(n_metadata_features, d_model // 4),
            nn.GELU(),
            nn.Linear(d_model // 4, d_model),
        )

        # Event type embedding
        self.type_embed = nn.Embedding(n_event_types, d_model)

        # Sequential position embedding
        self.pos_embed = nn.Embedding(max_events, d_model)

        self.norm = nn.LayerNorm(d_model)
        self.dropout_layer = nn.Dropout(dropout)

    def forward(
        self,
        content_embeddings: torch.Tensor,   # [B, N, content_embed_dim]
        metadata_features: torch.Tensor,     # [B, N, n_metadata_features]
        event_types: torch.Tensor,           # [B, N] categorical
        positions: torch.Tensor,             # [B, N] sequential position
    ) -> torch.Tensor:
        """Returns: h [B, N, d_model]"""
        h = (self.content_proj(content_embeddings)
             + self.metadata_proj(metadata_features)
             + self.type_embed(event_types)
             + self.pos_embed(positions))
        return self.dropout_layer(self.norm(h))
```

### New Module: StateReadout

Create `liquid_arc/state_readout.py`:

```python
"""State readout — project ODE state into outputs for Claude.

Produces:
  1. Relevance scores: per-event relevance to current focus [N]
  2. State summary: compressed current understanding [d_summary]
  3. Goal status: per-goal completion/priority [n_goals, 2]
  4. Focus indices: top-K events Claude should attend to [K]

These are PROJECTIONS — they don't modify h.
"""

import torch
import torch.nn as nn


class StateReadout(nn.Module):
    def __init__(self, d_model: int = 768, d_summary: int = 256, max_events: int = 128):
        super().__init__()

        self.relevance_head = nn.Sequential(
            nn.LayerNorm(d_model),
            nn.Linear(d_model, d_model // 4),
            nn.GELU(),
            nn.Linear(d_model // 4, 1),
        )

        self.summary_query = nn.Parameter(torch.randn(1, 1, d_model) * 0.02)
        self.summary_proj = nn.Sequential(
            nn.LayerNorm(d_model),
            nn.Linear(d_model, d_summary),
        )

        self.goal_head = nn.Sequential(
            nn.LayerNorm(d_model),
            nn.Linear(d_model, d_model // 4),
            nn.GELU(),
            nn.Linear(d_model // 4, 2),
            nn.Sigmoid(),
        )

        self.focus_head = nn.Sequential(
            nn.LayerNorm(d_model),
            nn.Linear(d_model, d_model // 4),
            nn.GELU(),
            nn.Linear(d_model // 4, 1),
        )

    def forward(self, h: torch.Tensor, event_types: torch.Tensor):
        B, N, d = h.shape

        relevance = self.relevance_head(h).squeeze(-1)
        relevance_scores = torch.sigmoid(relevance)

        query = self.summary_query.expand(B, -1, -1)
        attn_weights = torch.bmm(query, h.transpose(1, 2)) / (d ** 0.5)
        attn_weights = torch.softmax(attn_weights, dim=-1)
        summary_state = torch.bmm(attn_weights, h).squeeze(1)
        summary = self.summary_proj(summary_state)

        goal_status = self.goal_head(h)

        focus_scores = self.focus_head(h).squeeze(-1)
        top_k = min(5, N)
        focus_values, focus_indices = torch.topk(focus_scores, top_k, dim=-1)

        return {
            'relevance_scores': relevance_scores,
            'summary': summary,
            'goal_status': goal_status,
            'focus_indices': focus_indices,
            'focus_scores': torch.sigmoid(focus_values),
        }
```

### Core: LiquidARCMind

Create `liquid_arc/mind.py`:

This wraps the ContinuousLifecycleRunner with conversation-specific embedding and readout, replacing the RoboticsEmbedding and ActionHead.

```python
"""LiquidARC Mind — persistent state controller for conversation.

Wraps ContinuousLifecycleRunner with:
  - ConversationEmbedding (replaces RoboticsEmbedding)
  - StateReadout (replaces ActionHead)
  - Event buffer management
  - Thread-safe autonomous processing
  - Online learning from feedback

CRITICAL STABILITY NOTES (from lifecycle/adaptive autonomy experiments):
  1. NEVER use ||dh/dt|| as a curiosity reward — causes NaN every time.
     Use prediction error ||embed(obs) - h|| instead — bounded by embedding scale.
  2. Include efficiency regularizer (λ_eff=0.001-0.005) on autonomous dynamics
     to prevent degenerate behavior and runaway dynamics.
  3. All GPU operations must go through a single thread or use a threading lock —
     concurrent CUDA calls from main thread + autonomous thread cause races.
  4. Adaptive damping in dynamics: dh_dt *= threshold/(||dh_dt|| + threshold)
     must be active — this was the critical fix preventing NaN in lifecycle runs.
"""

import torch
import torch.nn as nn
import threading
import time
from typing import Any, Dict, List, Optional

from .config import LiquidARCConfig
from .lifecycle import ContinuousLifecycleRunner, SensoryForcing
from .conversation_embedding import ConversationEmbedding
from .state_readout import StateReadout
from .context_pool import ContextPool
from .dynamics import ContinuousDynamics


class LiquidARCMind:
    """Persistent conversational mind.

    The ODE state h lives as long as the server runs.
    Events arrive as sensory forcing. Context is read from h.
    Between events, autonomous dynamics consolidate.
    """

    def __init__(
        self,
        checkpoint_path: str,
        config: LiquidARCConfig,
        text_embedder: Any,
        device: str = 'cuda',
        max_context_events: int = 64,
        lambda_eff: float = 0.001,
    ):
        self.device = device
        self.text_embedder = text_embedder
        self.max_events = max_context_events
        self.lambda_eff = lambda_eff

        d = config.d_model

        # Core dynamics (from checkpoint)
        self.dynamics = ContinuousDynamics(config).to(device)
        self.context_pool = ContextPool(config).to(device)

        # Load checkpoint weights for dynamics + context_pool
        ckpt = torch.load(checkpoint_path, map_location=device)
        state_dict = ckpt['model_state_dict'] if 'model_state_dict' in ckpt else ckpt
        dynamics_keys = {k: v for k, v in state_dict.items()
                        if k.startswith('dynamics.') or k.startswith('context_pool.')}
        # Load into a temporary dict-holder to use load_state_dict
        holder = nn.ModuleDict({'dynamics': self.dynamics, 'context_pool': self.context_pool})
        holder.load_state_dict(dynamics_keys, strict=False)
        print(f"Loaded {len(dynamics_keys)} dynamics/context_pool parameters")

        # Conversation-specific modules (new, randomly initialized)
        self.embedding = ConversationEmbedding(
            d_model=d,
            content_embed_dim=384,
            n_metadata_features=8,
            max_events=max_context_events,
        ).to(device)

        self.forcing = SensoryForcing(d_model=d, n_entities=max_context_events).to(device)

        self.readout = StateReadout(
            d_model=d, d_summary=256, max_events=max_context_events,
        ).to(device)

        # Persistent ODE state
        self._h: Optional[torch.Tensor] = None
        self._gpu_lock = threading.Lock()  # Serialize all GPU operations

        # Event buffer
        self.events: List[Dict] = []
        self.event_count = 0
        self._last_event_time = time.time()

        # Integration config
        self.T = getattr(config, 'integration_time', 2.0)
        self.internal_steps = 16

        # Online learning
        self.optimizer = torch.optim.Adam(
            list(self.embedding.parameters()) +
            list(self.forcing.parameters()) +
            list(self.readout.parameters()),
            # NOTE: dynamics NOT in optimizer for Phase 1 (frozen dynamics).
            # Add dynamics params for Phase 2 (online fine-tuning).
            lr=1e-5,
        )

        # Autonomous processing thread
        self._running = False
        self._auto_thread = None

        # Initialize state
        self._h = torch.zeros(1, max_context_events, d, device=device)

    # ──────────────────── TEXT EMBEDDING (LOCAL) ────────────────────

    def _embed_text(self, text: str) -> torch.Tensor:
        """Embed text using local model. NEVER leaves the Spark."""
        with torch.no_grad():
            emb = self.text_embedder.encode(text, convert_to_tensor=True)
        return emb.to(self.device)

    # ──────────────────── EVENT MANAGEMENT ────────────────────

    def _build_metadata(self, event_type: str, content: str,
                        metadata: Optional[Dict]) -> torch.Tensor:
        now = time.time()
        time_delta = now - self._last_event_time
        self._last_event_time = now

        type_map = {
            'user_message': 0, 'assistant_message': 1, 'tool_result': 2,
            'goal': 3, 'context': 4, 'temporal': 5,
        }
        type_id = type_map.get(event_type, 0)

        meta = torch.zeros(8, device=self.device)
        meta[0] = min(time_delta, 600.0) / 600.0  # capped at 10 min, normalized
        meta[1] = min(len(content), 5000) / 5000.0
        meta[2] = float(metadata.get('sentiment', 0.0)) if metadata else 0.0
        meta[3] = float(metadata.get('confidence', 0.5)) if metadata else 0.5
        meta[4] = float(metadata.get('tool_count', 0)) if metadata else 0.0
        meta[5] = float(metadata.get('success', 1.0)) if metadata else 1.0
        meta[6] = min(self.event_count, 500) / 500.0
        meta[7] = type_id / 5.0
        return meta, type_id

    def _tokenize_current_events(self) -> Dict[str, torch.Tensor]:
        N = min(len(self.events), self.max_events)
        recent = self.events[-N:]

        content_embs = torch.stack([e['embedding'] for e in recent]).unsqueeze(0)
        metadata = torch.stack([e['metadata'] for e in recent]).unsqueeze(0)
        types = torch.tensor([e['type'] for e in recent], device=self.device).unsqueeze(0)
        positions = torch.arange(N, device=self.device).unsqueeze(0)

        return {
            'content_embeddings': content_embs,
            'metadata_features': metadata,
            'event_types': types,
            'positions': positions,
            'n_events': N,
        }

    # ──────────────────── ODE INTEGRATION ────────────────────

    def _run_ode_segment(self, h: torch.Tensor, n_steps: int,
                         forcing: Optional[torch.Tensor] = None,
                         return_efficiency: bool = False):
        """Run n_steps of ODE. Thread-safe via _gpu_lock (caller must hold lock).

        Returns (h_final, prediction_error_mean).
        If return_efficiency=True, also returns efficiency_cost for regularizer.
        """
        dt = self.T / n_steps
        t = 0.0
        eff_accum = torch.tensor(0.0, device=h.device)

        for i in range(n_steps):
            if hasattr(self.dynamics, 'set_step_embed'):
                self.dynamics.set_step_embed(i, n_steps)
            if hasattr(self.dynamics, 'set_step_index'):
                self.dynamics.set_step_index(i, n_steps)

            dy = self.dynamics(t, h)

            # Sensory forcing with linear decay
            if forcing is not None:
                decay = 1.0 - (i / n_steps)
                dy = dy + decay * forcing

            # Efficiency cost tracking
            if return_efficiency:
                eff_accum = eff_accum + (dy.detach() ** 2).mean()

            h = h + dt * dy
            t = t + dt

        if return_efficiency:
            return h, eff_accum / n_steps
        return h

    # ──────────────────── CORE METHODS (MCP tools call these) ────────────────────

    def observe_event(self, event_type: str, content: str,
                      metadata: Optional[Dict] = None) -> Dict:
        """Inject a conversation event as sensory forcing.

        SAFE CURIOSITY: Uses prediction error ||embed(obs) - h||,
        NOT dynamics magnitude ||dh/dt|| (which causes NaN).
        """
        embedding = self._embed_text(content)
        meta, type_id = self._build_metadata(event_type, content, metadata)

        self.events.append({
            'embedding': embedding,
            'metadata': meta,
            'type': type_id,
            'content_preview': content[:200],
            'timestamp': time.time(),
        })
        self.event_count += 1

        if len(self.events) > self.max_events:
            self.events = self.events[-self.max_events:]

        with self._gpu_lock:
            tokens = self._tokenize_current_events()
            N = tokens['n_events']
            obs_embed = self.embedding(**{k: v for k, v in tokens.items() if k != 'n_events'})

            # Prediction error: SAFE curiosity signal (bounded by embedding magnitude)
            h_slice = self._h[:, :N, :]
            prediction_error = self.forcing.get_prediction_error(h_slice, obs_embed)
            forcing = self.forcing.compute_forcing(h_slice, obs_embed)

            # Context from current state (not fresh embedding)
            context_mask = torch.ones(1, N, dtype=torch.bool, device=self.device)
            context = self.context_pool(h_slice, context_mask)
            self.dynamics.set_context(context, mask=None)
            self.dynamics.set_n_steps(self.internal_steps)

            # ODE with sensory forcing
            h_new = self._run_ode_segment(h_slice, self.internal_steps, forcing=forcing)

            # Update persistent state (detached)
            self._h = self._h.clone()
            self._h[:, :N, :] = h_new.detach()

            # Diagnostics
            g = self.dynamics.compute_metric(h_new.detach())
            cv = (g.std() / (g.mean() + 1e-8)).item()

        return {
            'prediction_error': prediction_error.mean().item(),
            'prediction_error_per_event': prediction_error[0].cpu().tolist()[:10],
            'cv': cv,
            'events_in_context': len(self.events),
            'h_norm': h_new.detach().norm().item(),
        }

    def get_context(self, query: Optional[str] = None) -> Dict:
        """Read current relevance scores, summary, and focus directives."""
        if self._h is None or len(self.events) == 0:
            return {'status': 'no_state', 'events': []}

        with self._gpu_lock:
            N = min(len(self.events), self.max_events)
            h_current = self._h[:, :N, :]
            event_types = torch.tensor(
                [e['type'] for e in self.events[-N:]], device=self.device
            ).unsqueeze(0)

            with torch.no_grad():
                readout_result = self.readout(h_current, event_types)

        relevance = readout_result['relevance_scores'][0].cpu().tolist()
        focus_idx = readout_result['focus_indices'][0].cpu().tolist()
        focus_scores = readout_result['focus_scores'][0].cpu().tolist()

        recent = self.events[-N:]
        context_items = []
        for i, (event, rel) in enumerate(zip(recent, relevance)):
            context_items.append({
                'index': i,
                'type': ['user_msg', 'assistant_msg', 'tool_result',
                         'goal', 'context', 'temporal'][event['type']],
                'preview': event['content_preview'],
                'relevance': round(rel, 3),
                'age_seconds': round(time.time() - event['timestamp'], 1),
            })

        context_items.sort(key=lambda x: x['relevance'], reverse=True)

        return {
            'status': 'active',
            'n_events': N,
            'context': context_items,
            'focus_indices': focus_idx,
            'focus_scores': focus_scores,
            'summary_norm': readout_result['summary'].norm().item(),
        }

    def get_diagnostics(self) -> Dict:
        """Read model internals for monitoring."""
        if self._h is None:
            return {'status': 'inactive'}

        with self._gpu_lock:
            h = self._h
            N = min(len(self.events), self.max_events)
            if N == 0:
                return {'status': 'no_events', 'h_norm': h.norm().item()}

            g = self.dynamics.compute_metric(h[:, :N, :].detach())
            tau = self.dynamics.compute_tau(h[:, :N, :].detach())
            beta = self.forcing.beta[:N]

        return {
            'status': 'active',
            'h_norm': h.norm().item(),
            'metric_cv': (g.std() / (g.mean() + 1e-8)).item(),
            'tau_mean': tau.mean().item(),
            'tau_std': tau.std().item(),
            'beta_mean': beta.mean().item(),
            'beta_std': beta.std().item(),
            'beta_per_type': {
                'user_msg': beta[0].item() if N > 0 else 0,
                'goal': beta[min(3, N-1)].item() if N > 3 else 0,
            },
            'events_in_context': N,
            'event_count_total': self.event_count,
        }

    def provide_feedback(self, event_index: int, feedback_type: str,
                         signal: float = 1.0) -> Dict:
        """Online learning from human feedback.

        Phase 1: Gradients flow through readout only (h detached).
        This updates relevance scoring without touching dynamics.
        """
        if event_index >= len(self.events):
            return {'status': 'invalid_index'}

        with self._gpu_lock:
            N = min(len(self.events), self.max_events)
            h = self._h[:, :N, :].detach().requires_grad_(True)
            event_types = torch.tensor(
                [e['type'] for e in self.events[-N:]], device=self.device
            ).unsqueeze(0)

            readout_result = self.readout(h, event_types)
            relevance = readout_result['relevance_scores'][0, event_index]

            if feedback_type == 'correct':
                loss = -torch.log(relevance + 1e-8) * signal
            elif feedback_type == 'wrong':
                loss = -torch.log(1 - relevance + 1e-8) * signal
            elif feedback_type == 'irrelevant':
                loss = relevance * signal
            else:
                return {'status': 'unknown_feedback_type'}

            self.optimizer.zero_grad()
            loss.backward()
            torch.nn.utils.clip_grad_norm_(
                list(self.embedding.parameters()) +
                list(self.readout.parameters()) +
                list(self.forcing.parameters()),
                max_norm=0.1,
            )
            self.optimizer.step()

        return {
            'status': 'updated',
            'loss': loss.item(),
            'relevance_at_feedback': relevance.item(),
        }

    def reset(self):
        """Reset state for new conversation/topic."""
        with self._gpu_lock:
            self.events = []
            self.event_count = 0
            self._h = torch.zeros_like(self._h)
            self._last_event_time = time.time()

    # ──────────────────── AUTONOMOUS PROCESSING ────────────────────

    def start_autonomous(self):
        """Background thread: efficiency-gated autonomous dynamics.

        CRITICAL: Uses efficiency regularizer to prevent runaway dynamics.
        Does NOT use ||dh/dt|| as curiosity (causes NaN).
        All GPU operations serialized through _gpu_lock.
        """
        self._running = True

        def _loop():
            while self._running:
                if self._h is not None and len(self.events) > 0:
                    with self._gpu_lock:
                        try:
                            N = min(len(self.events), self.max_events)
                            h_slice = self._h[:, :N, :]

                            context_mask = torch.ones(1, N, dtype=torch.bool,
                                                      device=self.device)
                            context = self.context_pool(h_slice, context_mask)
                            self.dynamics.set_context(context, mask=None)
                            self.dynamics.set_n_steps(16)

                            with torch.no_grad():
                                h_auto = self._run_ode_segment(
                                    h_slice, 16, forcing=None)

                            self._h[:, :N, :] = h_auto
                        except Exception as e:
                            print(f"Autonomous processing error: {e}")

                time.sleep(1.0)

        self._auto_thread = threading.Thread(target=_loop, daemon=True)
        self._auto_thread.start()

    def stop_autonomous(self):
        self._running = False
        if self._auto_thread:
            self._auto_thread.join(timeout=5.0)
```

## Stability Requirements (from lifecycle/adaptive autonomy experiments)

These are NON-NEGOTIABLE. Every one was discovered through a crash or exploit:

| Requirement | Why | Implementation |
|---|---|---|
| Adaptive damping | Prevents NaN from dynamics runaway | `dh_dt *= threshold/(norm + threshold)` in dynamics.forward() |
| No ||dh/dt|| curiosity | Rewards instability → NaN every time | Use prediction error `||embed(obs) - h||` only |
| Efficiency regularizer | Prevents degenerate strategies + stabilizes dynamics | `λ_eff * mean(dy²)` as loss term during online learning |
| GPU lock | Concurrent CUDA ops from threads cause races | `threading.Lock()` around all GPU operations |
| Gradient clipping | Online learning updates must be conservative | `clip_grad_norm_(params, max_norm=0.1)` |
| NaN detection | Skip updates with invalid loss | `if torch.isnan(loss): return` |

## Config

Create `configs/linguistic_mind.yaml`:

```yaml
# LiquidARC Mind — Linguistic State Controller
d_model: 768
d_metric: 192
d_ffn: 1536
n_ode_steps: 16
integration_time: 2.0
tau_min: 0.5
tau_max: 1.0
dropout: 0.1

# Ensure stability fixes are active
use_torch_compile: false  # Not needed for MCP server (events arrive at human speed)

# CV floor/ceiling (from original training)
cv_floor_target: 3.0
cv_ceiling_target: 8.0
cv_floor_lambda: 0.1

# Conversation-specific
max_context_events: 64
content_embed_dim: 384
n_metadata_features: 8
n_event_types: 8

# Online learning
online_lr: 0.00001
feedback_grad_clip: 0.1
lambda_eff: 0.001

# MCP server
port: 8420
host: "0.0.0.0"
```

**Note on torch.compile:** The MCP server does NOT need torch.compile. Conversation events arrive at human typing speed (seconds between events), not 120Hz physics rate. Eager mode is fine and avoids compilation complexity. The 5-minute compile startup is unnecessary for a server that needs to start quickly.

## Text Embedding: Local Privacy

Content embeddings MUST be generated locally. Conversation data never leaves the Spark.

**Recommended:** sentence-transformers with `all-MiniLM-L6-v2`:
```bash
pip install sentence-transformers --break-system-packages
```

22M parameters, 384-dim output, runs on GPU alongside LiquidARC. Fast enough for per-message embedding (< 10ms per message).

**Fallback** if GPU memory is tight: use CPU-only embedding with `device='cpu'` in the SentenceTransformer constructor.

## Experimental Protocol

### Phase 1: Basic MCP Integration (Frozen Dynamics, No Online Learning)

Deploy with dynamics frozen and online learning disabled. Validate the pipeline works.

```bash
python -m liquid_arc.mcp_serve \
  --checkpoint /workspace/liquid-arc/PRECIOUS_CHECKPOINTS/5m_post_transition.pt \
  --config configs/linguistic_mind.yaml \
  --port 8420 \
  --freeze_dynamics \
  --no_online_learning
```

Test:
- observe_event for 10+ conversation turns — does h_norm stay bounded? Does CV adapt?
- get_context — do relevance scores produce any meaningful ordering?
- Prediction error — does it spike on topic changes?
- Beta — does per-event-type differentiation emerge even without online learning?

### Phase 2: Online Learning from Feedback

Enable feedback-driven updates (readout head only, dynamics still frozen):

```bash
python -m liquid_arc.mcp_serve \
  --checkpoint [SAME] \
  --config configs/linguistic_mind.yaml \
  --port 8420 \
  --freeze_dynamics \
  --online_lr 1e-5
```

After 20+ feedback events, compare relevance quality to Phase 1. Does the readout improve?

### Phase 3: Autonomous Processing

Enable the background thread for between-event consolidation:

```bash
python -m liquid_arc.mcp_serve \
  --checkpoint [SAME] \
  --config configs/linguistic_mind.yaml \
  --port 8420 \
  --freeze_dynamics \
  --online_lr 1e-5 \
  --enable_autonomous
```

Monitor h_norm between events. Does the state evolve during idle time? Does get_context return different results after 30 seconds of idle vs immediately after an event?

### Phase 4: Unfrozen Dynamics + Multi-Session

Enable full online learning including dynamics:

```bash
python -m liquid_arc.mcp_serve \
  --checkpoint [SAME] \
  --config configs/linguistic_mind.yaml \
  --port 8420 \
  --online_lr 1e-5 \
  --enable_autonomous \
  --lambda_eff 0.001
```

Run across multiple conversations over days. Save checkpoints. Track CV trajectory — does a phase transition occur in the conversational domain?

## Success Criteria

### Phase 1
- **Minimum:** Server runs stably for hours. observe_event and get_context work without crash.
- **Good:** Prediction error spikes on topic changes. Relevance scores show any non-trivial ordering.
- **Strong:** CV adapts measurably across different conversation types.

### Phase 2
- **Minimum:** Feedback updates don't crash or diverge.
- **Good:** Relevance accuracy improves measurably over 20+ feedback events.
- **Strong:** Model develops user-specific preferences not present at initialization.

### Phase 3
- **Minimum:** Autonomous thread runs without interfering with event processing.
- **Good:** h_norm evolves during idle time (model consolidating).

### Phase 4
- **Headline:** Phase transition in conversational domain — CV shifts as the model discovers conversational structure, paralleling the two phase transitions on Anymal.
